# SoulFire brand

Shared guidance for SoulFire's identity, product language, and naming across repositories.

![SoulFire cyan flame on a dark background](assets/icons/icon-rounded.svg)

SoulFire automates Minecraft players for server testing, automation, and development.
People use the app, CLI, SDKs, and visual scripts to observe and control bots.

## Current guidance and proposals

The guides establish the vocabulary baseline for new work. Existing interfaces can use older labels.
This repository does not change an API, file format, or released feature by itself.

[Proposals](proposals/README.md) contain changes that need a maintainer decision.
[Decision 001](decisions/001-display-name-migration.md) accepts **Project** and the selected display-name migration.
Implementation and release remain separate from acceptance. Other proposal items remain unapproved.

[Decision records](decisions/README.md) document accepted or rejected proposals and their implementation plans.

## Contribute

Read [Contributing](CONTRIBUTING.md) before changing a shared term or importing an asset.
Keep implementation details and API references in their owning repositories.
Link to these guides from repository instructions instead of copying them.
